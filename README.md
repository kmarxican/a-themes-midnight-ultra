# Midnight.Ultra by The A-Themes

![Midnight.Ultra Screenshot](https://github.com/kmarxican/a-themes-midnight-ultra/raw/main/mu-screenshot.png)

The Midnight.Ultra theme is inspired by the code preview that is used on programmingfonts.com and CodeMirror Midnight theme. Colors have been choosen to reduce eyestrain, improve readability, functionality, and color harmony. 

Our goal is to provide the best, most complete themes available to the VS code community. These themes are provided free as a thank you to the community for all of their contributions to the VS code project. It is our hope that by providing the best work surface for you that you are able to produce the best product. Each theme is maticulously crafted and tested. 



*Credit goes to Javascript Garden, CodeMirror, and programmingfonts.com for creating such a beautiful and functional design.*
